# Chat System

## Goal

Build a production-ready Messenger-like chat backend using FastAPI and PostgreSQL.

This project focuses on learning backend development through Layered Architecture and gradually evolves into a scalable distributed system.

## Objectives

### Current Version

- Layered Architecture
- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- JWT Authentication
- Redis Cache
### Future Versions

- WebSocket
- RabbitMQ
- Docker
- Kubernetes
- Monitoring
- CI/CD

## Features

- Authentication
- User Management
- Private Chat
- Group Chat
- Message Reply
- File Upload
- Read Receipt

## Tech Stack

- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- Pydantic
